About

Built for Leonida’s files

RedaX is an independent RPF9 exploration tool made to simplify navigating and inspecting Grand Theft Auto VI game files. It brings a clean, efficient desktop experience to the RAGE engine’s archives.

Open an archive. Inspect what’s inside. Browse every entry, all in one modern interface.
Features

Everything you need inside the archive

Archive, model, texture and shader tools for exploring GTA VI’s next-generation RAGE engine files, with editing and replacing built in.

RPF9 Archive Explorer

Open and explore GTA VI RPF9 archives.

3D Model Viewer

Preview 3D models found inside the archives.

TTPF Texture Explorer

Browse and inspect TTPF textures from the game files.

Shader Explorer

Look through the game’s shaders in a dedicated view.

Edit & Replace

Edit entries and replace files inside archives.

Archive inspection

Inspect archive information and every available file entry.

File browsing

Navigate discovered archive contents through a desktop interface.

Modern GUI

A dedicated Windows app designed around a clean experience.

Performance focused

Built on modern .NET technology for speed.

GTA VI focused

Made specifically for the next generation of RAGE engine game files.
